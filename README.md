# 🍎 FruitGarden - Organic Food E-commerce

Hệ thống thương mại điện tử chuyên cung cấp nông sản sạch, bao gồm **Admin Dashboard** (Quản lý) và **Storefront** (Bán hàng).

## 🚀 Tính năng nổi bật (Key Features)

### 1. Phân hệ Admin (Quản trị viên)
- [x] **Dashboard:** Biểu đồ thống kê doanh thu (Chart.js), tỷ lệ danh mục.
- [x] **Quản lý sản phẩm:** CRUD, cảnh báo tồn kho thấp.
- [x] **Quản lý đơn hàng:** Cập nhật trạng thái xử lý/giao hàng.

### 2. Phân hệ Client (Khách hàng)
- [x] **Trang chủ hiện đại:** Banner Slider (SwiperJS), hiệu ứng cuộn trang (AOS).
- [x] **Giỏ hàng Dynamic:**
    - Tự động tính tổng tiền khi thay đổi số lượng.
    - Tính toán thuế VAT (8%) và phí vận chuyển tự động.
- [x] **Hệ thống thông báo:** Custom Toast Messages (Success/Error) không dùng thư viện nặng.
- [x] **Tài khoản:** Đăng ký, Đăng nhập, Chỉnh sửa Profile cá nhân.

## 🛠 Công nghệ sử dụng (Tech Stack)

| Hạng mục | Công nghệ |
| :--- | :--- |
| **Backend** | Java (Spring Boot), Hibernate, MySQL |
| **Frontend Admin** | Thymeleaf, Bootstrap 5, Chart.js |
| **Frontend User** | HTML5, CSS3, JavaScript (ES6), SwiperJS, AOS |
| **Tools** | Git, IntelliJ IDEA, Maven |
